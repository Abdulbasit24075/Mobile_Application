🌦️ WeatherWhiz — An Intelligent Weather & Lifestyle Assistant

WeatherWhiz is a modern, intelligent, and user-centric weather application designed to do more than just show forecasts. It combines real-time weather data, personalized insights, and wellness features to help users make better daily decisions based on their location, age, and environmental conditions.

The app is built using Flutter for a smooth cross-platform experience and integrates live weather APIs, Firebase Authentication, and Firestore for secure and personalized data handling.

🔐 Smart Authentication System (Login + Guest Mode)

WeatherWhiz supports two modes of access:

👤 Logged-In Users

Secure login using email & password (Firebase Authentication)

Personal profile with saved preferences

City, age, theme, and wellness settings are stored securely in Firestore

👥 Guest Mode

No login required

Instant access to core weather features

Profile and personalization features are hidden

A clear “Login” option is always available for upgrading to full access

This dual-mode system ensures maximum accessibility while maintaining data security.

🌍 Comprehensive Weather Features

WeatherWhiz uses real-time weather APIs to deliver accurate and detailed information:

🔎 Search weather by city name

📍 Get weather using current GPS location

🗺️ Select city using an interactive map

🕒 Hourly forecast (next 8 hours)

📆 Extended forecast (up to 7 days)

🌡️ Temperature, humidity, wind speed, pressure & visibility

All weather data is processed intelligently to generate meaningful insights instead of raw numbers.

⚠️ Weather Safety Alerts & Precautions

One of the app’s standout features is the User Alerts System, which analyzes live weather conditions and provides:

🌫️ Air quality alerts (smoke, haze, low visibility)

🔥 Heatwave warnings
❄️ Cold weather alerts
🌧️ Rain & thunderstorm warning
💨 Strong wind advisories
✈️ Travel safety recommendations
🚫 Outdoor activity warnings

Each alert includes:

Severity level (Low / Medium / High)

Clear explanation

Practical safety tips

These alerts help users stay safe, not just informed.

👕 Age-Based Clothing Recommendations

WeatherWhiz intelligently suggests clothing choices by combining:

User’s age group
Real-time weather conditions
Temperature, wind, humidity & visibility
Different logic is applied for:
Babies & children
Teenagers
Adults
Senior citizens

This makes the app especially useful for families, parents, and elderly users.

🧘 Wellness & Meditation Integration

WeatherWhiz promotes mental well-being through a Meditation & Healthy Mind feature:

Personalized meditation sound suggestions based on weather
Calm sounds such as rain, birds, waterfall, and fire
User-selectable meditation duration (timer)
Play / stop controls
Preference saved per user profile

This unique feature connects weather conditions with mental wellness, making WeatherWhiz more than a traditional weather app.

🎨 Dark Mode & Personalized UI

Light & Dark themes

Smooth animations and modern UI design

Adaptive gradients based on theme
